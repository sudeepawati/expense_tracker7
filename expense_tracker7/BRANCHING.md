# Expense Tracker - Git Branching Strategy

## Main Branch
main is the stable branch containing the completed project.

## Feature Branches
Each developer works on a separate feature branch.

- feature/add-expense
- feature/view-expense

## Workflow
1. Create a feature branch from main.
2. Develop the assigned feature.
3. Commit changes with meaningful messages.
4. Merge completed features into main.
5. Resolve conflicts before completing the merge.

## Team
- Team Leader: Project setup and integration
- Developer 2: Add Expense feature
- Developer 3: View Expense feature
